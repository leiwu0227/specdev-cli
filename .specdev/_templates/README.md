# Templates

SpecDev creates current Assignment, Mission, Discussion, result, and receipt
artifacts through semantic commands. It has no separate set of contract,
Task-document, reviewer-persona, or custom agent-spec templates.

`faq.md` is the one optional living-knowledge template. Copy it into
`knowledge/faq/` and replace every placeholder. Cite the durable outcome sources.
Omit `review_after` for stable repository invariants.
