# Design: Roadmap Design-Node Guidance

Roadmap design-node guidance describes a direction of explanation rather than a
document schema. Except for `source_code_folder_structure.md`, each note starts with
general descriptions and becomes more specific using whatever Markdown organization
best fits the subject.

Every note other than `core_concepts.md` and `source_code_folder_structure.md` ends
by naming each targeted source file and assigning it a maximum total completed-file
line count. The guidance requires the information and its position, not a particular
representation.

A non-standard note may optionally use a small relevant folder tree and pseudocode
when they clarify responsibilities, relationships, or behavior. These remain
illustrations rather than implementation transcripts, and neither is a mandatory
section.
