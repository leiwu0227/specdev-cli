# Investigation

Define the question and a time limit. Search living knowledge and find entry
points with `rg`. Trace data and control flow. Separate verified facts from
assumptions. Run only narrow checks allowed by repository instructions.

For an Assignment, feed concise findings and file references into the single
contract. For exploratory thought work, use a code-read-only Discussion. Do not
create a separate research phase, breakdown, or automatic knowledge-capture step.
