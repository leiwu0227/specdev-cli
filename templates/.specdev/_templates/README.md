# Templates

SpecDev creates current Assignment, Mission, Discussion, result, and receipt
artifacts through semantic commands. There is intentionally no parallel set of
contract, Task-document, reviewer-persona, or custom agent-spec templates.

`faq.md` is the one optional living-knowledge template. Copy it into
`knowledge/faq/`, replace every placeholder, cite the durable outcome sources,
and omit `review_after` for stable repository invariants.
